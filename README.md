# Flutter Learning Roadmap

An interactive, phase-by-phase roadmap for learning Flutter, from programming basics to shipping an app. Tick off topics as you learn them and expand each phase to see what to study and which resources to use.

## Features

- Learning phases with a level (Beginner and up) and suggested duration
- Each phase has sections with topics and recommended resources
- Checkboxes to track completed topics
- Collapsible phases

Progress is kept in memory for the session and resets when you reload the page.

## Tech stack

React, Vite, Tailwind CSS, lucide-react

## Getting started

```bash
npm install
npm run dev
```

| Script | What it does |
|---|---|
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Lint with ESLint |

The roadmap content lives in `src/FlutterLearningRoadmap.jsx`.
